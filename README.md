# Pergunta norteadora

> Quais são as principais características sociodemográficas e como se distribuem as demandas e ofertas de cuidados no Rio Grande do Norte (RN), no Nordeste (NE) e no Brasil (BR)?

# Objetivo geral

Caracterizar o perfil sociodemográfico e analisar a distribuição das demandas e da provisão de cuidados no Rio Grande do Norte, Nordeste e Brasil, com foco na demanda associada às Doenças Crônicas Não Transmissíveis (DCNT).

# Objetivos específicos

1. Caracterizar o perfil sociodemográfico;
2. Identificar indicadores relacionados à demanda de cuidados;
3. Analisar a distribuição da demanda associada às DCNT;
4. Caracterizar a provisão de cuidados;
5. Comparar RN, NE e Brasil;
6. Identificar possíveis diferenças entre demanda e provisão.

# Metodologia

O projeto segue um fluxo de análise de dados composto pelas seguintes etapas:

**Raw Data → Exploration → Scrubbing → Analysis → Visualization → Results**

# Fonte dos dados

Os dados utilizados neste projeto foram obtidos a partir do dataset **Indicadores de Cuidado — RN, NE e Brasil**, disponibilizado no Kaggle por Jadson Chagas.
